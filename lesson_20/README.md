# Урок 20

Entity Framework Core: модели, Fluent API, DI и CRUD студентов и групп.

Запуск: `dotnet run --project College.csproj`. Откройте адрес из консоли. Подключение задаётся через ConnectionStrings__DefaultConnection. Для новой базы выполните SQL из ../database/CollegeDB.sql. Для существующей базы сначала проверьте соответствие схемы.
